🚀 Featured Projects & Write-ups

- "Bandit Write-ups" (https://github.com/udaybhale/bandit-writeups)
  Hands-on Linux, SSH, enumeration, file handling, and cybersecurity fundamentals through the OverTheWire Bandit wargame.

- "Guided Pentest: Web Write-up" (https://hackwithrudraub.hashnode.dev/)
  Practical web penetration testing methodology covering reconnaissance, enumeration, vulnerability identification, exploitation, and findings from a TryHackMe lab.

- "Secure Wi-Fi Project" (https://github.com/udaybhale/Secure-WiFi-Project)
  Cisco Packet Tracer project covering secure wireless configuration, WPA2 security, MAC filtering, and administrative hardening.

- "Nmap Scanning Project" (https://github.com/udaybhale/cs-internship-task1-nmap-scan)

  Cisco Packet Tracer lab demonstrating RIP v2 dynamic routing and classless IP addressing.
